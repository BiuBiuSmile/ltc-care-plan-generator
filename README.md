# 個管照顧計畫產生器 v9.8

本版將服務單位數輸入改成「每週計算／單次計算」可複選切換介面。

- 選取服務後，先選計算方式。
- 每週計算：每週次數 × 約 4.5 週。
- 單次計算：本月單次單位直接加入，不乘 4.5。
- 兩種可同時啟用，自動合併本月單位。
- 每張服務卡與 STEP 3 顯示「目前額度還能增加」，包含可增加的每週次數與單次服務單位。
- 後端資料格式維持 weekly_qty / single_qty / qty，因此 Worker v9.7 可直接沿用。

## v9.9 UI 整合修正
