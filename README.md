# 個管照顧計畫產生器 v6｜彈性模板版

本版根據多份實際個管照顧計畫的共同寫法，將原本較固定的模板改為「固定骨架＋彈性文字」。

## v6 主要變更

- 新增「計畫撰寫模式」：精簡／標準／詳細。
- 照顧面不再固定 2～4 點；AI 依模式與來源資料量調整。
- 經濟、環境、社交、家庭優勢若原文沒有資料，AI 回空字串，不再硬補「未載明」。
- 「三、照顧問題清單」改由 AI 依照專內容整理，但服務碼只能從使用者本次實際選取的服務碼中帶入。
- 服務碼、月單位、金額、部分負擔、照會單位仍完全由前端固定，不交給 AI 決定。
- 新增「特殊服務／其他核定事項」，可填 AA09、短照特殊說明等；有填寫時會動態新增一個照顧計畫項目，後面的送餐編號自動順延。
- 「服務介入後改變」新增：尚未使用、初評、待服務介入後填寫、穩定持續使用服務、自訂。
- 修正服務換算式：只有每週次數 × 4.5 與月單位吻合時才顯示，避免多單位/次的服務被錯誤推算。

## 部署

1. 先將 `renbao-csms-license-server_v2.6.3_care_plan_web_v6_彈性模板.txt` 貼到既有 Cloudflare Worker 並 Deploy。
2. 再將本資料夾內容上傳至 GitHub Repository `ltc-care-plan-generator` 根目錄，覆蓋舊檔。
3. 回網站按 Ctrl + F5 強制重新整理。

## 安全原則

- OpenAI API Key 只存在 Cloudflare Worker Secret。
- GitHub Pages 不存放 API Key。
- 個案照專原文不寫入 D1。
- `/care-plan-web` 與既有 `/openai-chat`、授權、試用、繳費 API 分離。
