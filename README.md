# 個管照顧計畫產生器 v10.0 穩定版

- 修正 BA17a / BA17d1 / BA09a / CB01a 等帶英文字尾服務碼的品質檢核。

- 修正管理者產生完成後按鈕文字被改回一般測試者模式。
