# 個管照顧計畫產生器 v10.3.2｜STEP 3 右側位置修正版

本版先處理測試者提出的實務流程問題；「自訂／切換輸出模板」暫不納入本版。


## v10.3.2 調整
- STEP 3「已選服務與額度」恢復原本位置：桌面版放回右側欄，平板／手機仍留在主流程。
- 其餘 v10.3 功能與 Worker 規則不變。

## v10.3 更新
- STEP 2 改為「服務類別選單」操作，減少一次攤開過多選項。
- 勾選聘用外籍看護後，依目前系統防呆規則鎖定 BA 照顧服務；若原本已選 BA，會先詢問是否移除。
- CMS 選定後自動帶出對應全日型日照：
  - CMS 2 → BB01
  - CMS 3 → BB03
  - CMS 4 → BB05
  - CMS 5 → BB07
  - CMS 6 → BB09
  - CMS 7 → BB11
  - CMS 8 → BB13
  切換 CMS 時，若已選全日型日照，會同步換成對應代碼。
- STEP 3 固定保留在 STEP 2 後方，不再於桌面版搬到右側欄。
- STEP 4 改為收合式選單，需要時再展開交通、輔具、喘息、餐飲與其他事項。
- STEP 5 增加派案彈性：
  - 指定單位：單位名稱必填。
  - 不指定單位：可先不填輪派單位。
  - 尚待照專／系統建置：可先完成計畫。
- 喘息服務加入年度額度：
  - CMS 2–6：32,340 元／年。
  - CMS 7–8：48,510 元／年。
  系統依所選 GA 項目單價 × 核定單位即時計算使用額度與剩餘額度，超額時禁止產生。
- Worker 同步加入外看 BA 衝突、CMS 日照型態、喘息年度額度與派案狀態的伺服器端驗證。
- 保留 v10.2.1「每個測試帳號各自 10 次／10 分鐘」AI 限流，不受同辦公室共用 IP 影響。

## 部署
1. 先更新 Cloudflare Worker v10.3。
2. 再將本資料夾檔案覆蓋 GitHub Pages repository 根目錄。

Google Apps Script、既有 Secrets、D1 binding 不需重新設定。
