# 個管照顧計畫產生器 v8｜實務穩定版

本版沿用 v7.1 的彈性模板與品質檢核，新增「全面服務防呆、局部 AI 重寫、可編輯結果＋AI 原稿復原」。

## v8 新增

### 1. 全面服務防呆
- 交通接送：填寫照會單位／電話時，自動啟用交通服務；關閉時若已有資料會先確認再清除。
- 輔具／無障礙：新增輔具項目或填寫額度資料時，自動啟用主項目；啟用但沒有任何輔具項目時，產生前會阻擋提醒。
- 喘息服務：延續 v7.1，勾 GA 項目會自動啟用；另外直接輸入核定次數時，也會自動勾選對應 GA 碼與主項目。
- 餐飲服務：填寫餐數或送餐單位時，自動啟用；啟用卻沒填餐／月時會阻擋。
- 外籍看護 30% 額度：填寫額度時自動啟用；關閉時若已有資料會先確認再清除。
- BA／專業／日照服務：維持「選取服務即為啟用」，且月單位數必填。

### 2. 局部 AI 重寫
完整計畫產生後，可只重寫：
- 照顧面
- 經濟面
- 環境面
- 社交面
- 個案／家庭優勢
- 照顧問題清單
- 服務執行說明

Worker 只要求 AI 回傳指定欄位的最小 JSON，其他 AI 區塊沿用上一版，固定服務資料仍由前端重新組版。

### 3. 可編輯結果＋AI 原稿
- 產出文字可直接修改。
- 手動修改後顯示「已手動修改」。
- 保留最近一次 AI 原稿，可按「復原 AI 原稿」。
- 修改後仍可按「重新檢核」。
- 若已有手動修改又執行局部重寫，會先提醒，避免誤蓋內容。

### 4. v7 品質檢核保留
- 服務碼一致性
- 月單位數
- CMS / 身分別
- 照顧服務金額 / 部分負擔
- 服務單位
- 問題清單對應
- 原文來源佐證

## 更新方式

1. Cloudflare Worker 全部覆蓋為 `Worker_v8_實務穩定版.txt` 後 Deploy。
2. 將本資料夾所有檔案覆蓋 GitHub Pages Repository 根目錄。
3. 等 GitHub Pages 部署完成後，以 Ctrl + F5 強制重新整理。

## 建議測試

1. 勾 BA07、BA13，再勾 GA09 並填 42，確認最終計畫有 GA09。
2. 直接在 GA09 次數欄輸入 42，不先勾核取方塊，確認系統自動勾選 GA09 與喘息服務。
3. 只填餐飲 62 餐，確認餐飲服務自動啟用。
4. 啟用輔具卻不新增項目，確認產生前會阻擋。
5. 完整產生後，單獨重寫「照顧面」，確認其他區塊仍保留。
6. 手動修改產出文字，確認顯示「已手動修改」，並可復原 AI 原稿。
