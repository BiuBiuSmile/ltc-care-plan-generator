# 個管照顧計畫產生器 v7｜品質檢核版

本版沿用 v6 彈性模板，新增「產出後自動品質檢核」。

## v7 新增

- 服務碼一致性：檢查是否漏掉核定碼、是否出現未允許服務碼，並檢查 AI 原始回傳是否曾嘗試使用未允許碼。
- 月單位數：逐項比對使用者選擇的月單位與最終計畫。
- CMS / 身分別：核對 CMS 等級、額度與身分別。
- 金額 / 部分負擔：核對照顧／日照服務固定計算結果。
- 照會單位：核對指定或輪派單位。
- 問題清單對應：提示已選服務是否有連結至 AI 的照顧問題清單。
- 原文來源佐證：Worker 要求 AI 回傳短句原文片段，前端再確認該片段真的存在於照專來源。
- 使用者若直接修改產出文字，檢核狀態會標示為「內容已修改」，可按「重新檢核」。

## 注意

原文來源佐證是輔助檢查：它能確認 AI 提供的佐證片段可回查，但不代表每一句敘述都已完全由程式驗證，因此重要醫療、家庭、經濟內容仍應由個管人工確認。

## 更新方式

1. 先更新 Cloudflare Worker 為 v7 Worker。
2. 再將此資料夾內檔案覆蓋 GitHub Pages Repository 根目錄。
3. 部署完成後使用 Ctrl + F5 強制重新整理。
