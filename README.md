# 個管照顧計畫產生器 v10.1 穩定修正版

本版在 v10.0 基礎上再修正：

- CMS 未選時不再顯示假的超額／使用率，改顯示「—」與提示。
- 身分別未選時不再顯示 0 元部分負擔，改顯示「—」。
- 額度、CMS、外籍看護 30% 或服務數量變更時，「目前額度還能增加」會即時刷新。
- 喘息核定次數與餐飲餐／月皆必須為大於 0 的整數。
- 搭配 Worker v10.1：移除錯誤／開發 Origin、拒絕無 Origin 的 POST、身分別白名單驗證。
- 搭配 Worker v10.1：同一測試帳號同時間只允許一個 AI 請求處理，降低逾時後重送造成重複扣次。
- 管理頁剩餘 AI 統計改以有效測試帳號計算；刪除／停用帳號時同步清理 AI 請求狀態。

搭配 Worker v10.1 使用。
